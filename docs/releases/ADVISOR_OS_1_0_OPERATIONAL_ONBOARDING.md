# Advisor OS 1.0 — Operational Onboarding

## Start here

1. Open the canonical ForgeOS URL and sign in.
2. Read the first grounded priority before configuring anything.
3. Use Command Bar for the shortest path to a person, action, policy or quote.
4. Complete only the missing preferences: display name, time zone, monthly goal, notification mode and capture mode.

## Daily operating loop

```text
HOME_PRIORITY
→ AGENDA
→ COMMAND_BAR_OR_PERSON_WORKSPACE
→ REVIEWED_ACTION
→ TIMELINE_AND_NEXT_ACTION
→ ACTIVITY_AND_FORECAST
```

### Morning

- Review overdue, today and waiting work.
- Confirm the single most useful next action.
- Check the goal gap and current Forecast without treating estimates as facts.

### During the day

- Capture conversations by text, voice or one-tap outcome.
- Review Forge's structured draft before confirming it.
- Create quotes from the confirmed Person/Pipeline context.
- Record presentation outcomes and schedule the next action.

### Portfolio service

- Open the client workspace and verified Policy detail.
- Review payment, renewal, anniversary and contact-gap signals.
- Preview and confirm service actions through Next Action.
- Use complementary quote entry only after reviewing the context.

### Close of day

- Resolve or reschedule open appointments and follow-ups.
- Review Activity, Forecast, Reports and Compensation together.
- Close the session; logout must scrub private UI and reject late results.
