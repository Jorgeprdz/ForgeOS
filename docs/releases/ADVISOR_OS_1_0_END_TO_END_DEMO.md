# Advisor OS 1.0 — End-to-End Demonstration Script

```text
DURATION_TARGET=20_TO_30_MINUTES
DATA=DEMO_OR_AUTHORIZED_PRODUCTIVE_DATA
EXTERNAL_SIDE_EFFECTS=REVIEWED_ONLY
```

## 1. Entry and first value

- Enter Forge in a new session.
- Verify Benvenù shows one grounded priority before setup.
- Confirm partial sources remain honest and usable.

## 2. Command Bar and appointment

- Ask who should be contacted today.
- Open the selected Person.
- Prepare an appointment through a reviewed scheduling draft.
- Open Google Calendar and state explicitly that opening is not saving.

## 3. Outcome capture

- Dictate or type what happened.
- Review the structured outcome.
- Confirm it.
- Verify Timeline, Pipeline and Next Action continuity.

## 4. Quote and presentation

- Create or reopen a Quote from the same Person context.
- Preview the printable document.
- Exercise print, download and reopen.
- Record `FOLLOW_UP`, `ACCEPTED`, `REJECTED` or `POSTPONED`.

## 5. Conversion

- Use a confirmed sale and approved Application.
- Reconcile the existing Person and Account.
- Create or reuse verified Policy lineage through canonical authorities.
- Verify Portfolio visibility before Pipeline closes `CLOSED_WON`.

## 6. Portfolio service

- Open Client 360 and Policy Detail.
- Review payment, renewal and contact-gap signals.
- Prepare and confirm a service action.
- Prepare a complementary quote without auto-executing it.

## 7. Daily management

- Open Activity, Funnel, Forecast, Goal, Compensation and Reports.
- Verify all sources use the same advisor and period.
- Show that `EARNED` and `PAID` remain separate and unknown remains unknown.

## 8. Session closure

- Start one delayed read.
- Log out.
- Verify private UI is cleared and the delayed result is rejected.
- Log in again and verify only confirmed preferences return.
