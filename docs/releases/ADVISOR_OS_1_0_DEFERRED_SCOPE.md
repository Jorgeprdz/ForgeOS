# Advisor OS 1.0 — Deferred Scope

```text
VERSION=1.0.0
STATUS=DEFERRED_BEYOND_1_0
SOURCE=ADVISOR_OS_1_0_ACCEPTANCE_AND_DEFERRED_SCOPE
```

The following capabilities do not block 1.0 and require a separately governed release:

- autonomous outbound messaging;
- bidirectional Calendar synchronization;
- autonomous Pipeline advancement;
- autonomous ML training and model lifecycle;
- recruiting and Promotoria workflows;
- manager surveillance dashboards;
- corporate administration;
- new intelligence authorities where an existing canonical owner exists;
- carrier-specific core logic inside shared runtime;
- full product redesign;
- deep email automation;
- unbounded custom workflows.

## Re-entry rule

A deferred capability may return only when it has:

1. a named authority and source of truth;
2. explicit human-confirmation rules;
3. privacy and identity boundaries;
4. failure-closed behavior;
5. productive and public acceptance;
6. its own release scope.

```text
SILENT_SCOPE_EXPANSION=FORBIDDEN
ADVISOR_OS_1_0_SCOPE_REOPENED=NO
```
