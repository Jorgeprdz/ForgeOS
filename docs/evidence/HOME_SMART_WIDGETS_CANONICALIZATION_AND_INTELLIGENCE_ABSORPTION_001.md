# HOME Smart Widgets Canonicalization and Intelligence Absorption

## Scope

- Replaces the demonstrative `Plan de hoy` card with the highest-ranked productive Smart Widget.
- Replaces the demonstrative `Seguimiento prioritario` card with the second productive signal when available.
- Hides both static demo cards without deleting their historical markup.
- Removes the separate Advisor Intelligence mount from Home.
- Preserves Pack 07 intelligence contracts as backend composition assets.
- Exposes `¿Por qué?` as an explicit disclosure on each canonical action card.
- Uses honest empty states when a reliable signal cannot be calculated.

## Productive authorities reused

- Activity reporting bridge.
- Monthly confirmed-policy goal authority.
- Cartera future radar.
- Productive Smart Widget orchestrator and ranking.
- Advisor Forecast enrichment when available.

## Safety

- No message is sent automatically.
- No task is created automatically.
- No pipeline stage is advanced automatically.
- Review actions remain subject to human interaction.
- Unknown values are not converted to zero.
- Logout scrub and late-result rejection remain owned by the productive Home runtime.
