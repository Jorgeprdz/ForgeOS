# FORGE CARTERA 090A–090D — RELATIONSHIP CAPITAL 001

## Program position

Cartera 090 implements Roadmap Point 9: Relationship Capital and Network Context.

The goal is to understand the advisor's commercial network without converting trust into leverage. Cartera presents reviewed relationship context and hypotheses; Shared Intelligence / Relationship Graph remains the canonical graph authority.

## One-pass decomposition

### 090A — Reviewed graph projection

Compose existing Cartera 040 Relationship Memory and Cartera 060 Relationship Growth authorities into a read-only projection of:

- confirmed household, family, company, partner, team and professional-community context;
- referral and center-of-influence hypotheses requiring review;
- evidence references, source authority and truth class;
- explicit distinction between confirmed edges and hypotheses.

No relationship edge is created when account type, role or confirmation state is insufficient.

### 090B — Relationship-capital evidence boundary

Every review item must explain:

- why this relationship;
- why now;
- supporting evidence;
- uncertainty;
- the smallest useful action;
- what the advisor must confirm.

Opaque influence scores, relationship-value scores, referral probabilities, predicted revenue, commission values and final priority truth are prohibited.

### 090C — Governed human review handoff

A review envelope may prepare one bounded next step, but it cannot:

- mutate the canonical relationship graph;
- contact a person;
- send a message;
- create a task or calendar event;
- create a Pipeline opportunity;
- request a referral;
- generate a final message;
- decide final NBA priority.

Introduction and center-of-influence context require client-confirmed willingness before a review envelope can be prepared.

### 090D — Productive Capital Relacional surface

The Cartera product surface is mounted after 080D and before canonical Cartera route events. It shows confirmed relationship context, visible hypotheses, evidence, uncertainty and honest partial-source states.

The UI contains no score and performs local advisor review only.

## Reused authorities

| Input | Authority | 090 role |
|---|---|---|
| Relationship brief and confirmed account context | Cartera 040 / Relationship Memory read model | Read-only graph context |
| Referral and center-of-influence review candidates | Cartera 060 / Relationship Growth read model | Evidence-backed hypotheses |
| Canonical relationship graph | Shared Intelligence / Relationship Graph | Remains owner; not mutated |
| Final priority | Alfred / NBA | Remains disconnected from 090 ordering |
| Final conversation | NASH | Not generated by 090 |
| Opportunity lifecycle | Pipeline | No opportunity creation |

## Source-state behavior

- Relationship Growth is the required primary review source.
- Relationship Memory briefs are loaded only for a bounded set of relevant or explicitly requested people.
- Partial or unavailable memory reads remain visible as `PARTIAL` or `UNAVAILABLE`.
- Missing relationship context is never replaced with zero, a fabricated edge or an inferred score.
