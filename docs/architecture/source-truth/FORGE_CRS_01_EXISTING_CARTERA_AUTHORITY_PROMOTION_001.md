## CRS 01C — Shared read facade

A minimal stateless facade now composes existing read authorities for future cross-module consumers.

```text
FACADE=advisor-os/shared-commercial-model/crs-01-commercial-person-authority-facade.js
FACADE_CONTRACT=FORGE_COMMERCIAL_PERSON_AUTHORITY_FACADE
FACADE_VERSION=CRS-01-AUTHORITY-FACADE-001.1
STATEFUL_CACHE=NO
NEW_PERSISTENCE=NO
```

Permitted facade operations:

```text
loadPerson(personReference)
searchPeople(query, options)
loadPortfolio()
loadPolicyDetail(policyReference)
loadRelationshipBrief(personReference, options)
loadPersonAuthoritySnapshot(personReference, options)
```

The snapshot composes existing authorities and explicitly attributes them:

```text
PERSON_SOURCE=CARTERA_010B_COMMERCIAL_PERSON
DIRECTORY_SOURCE=CARTERA_010D_UNIFIED_DIRECTORY
POLICY_SOURCE=CARTERA_010C_CANONICAL_PORTFOLIO
RELATIONSHIP_BRIEF_SOURCE=CARTERA_040B_PERSON_RELATIONSHIP_BRIEF
```

The facade deliberately does not expose:

```text
createPerson
mergePerson
resolveIdentity
recordRelationshipMemory
createPolicy
updatePolicy
createOpportunity
createApplication
sendMessage
createTask
createCalendarEvent
```

Identity resolution remains a governed command authority. CRS 01 does not turn candidate search into automatic identity resolution.
