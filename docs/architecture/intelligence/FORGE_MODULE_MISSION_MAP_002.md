# Forge Module Mission Map 002

Phase: `FORGE_INTELLIGENCE_ASSEMBLY_BLUEPRINT_002`

A module is a workspace, not a truth owner unless its domain authority explicitly owns the underlying fact/rule. Each module must answer one primary question.

| Module | Mission | Primary user question | Primary decision | Authoritative inputs | Intelligence consumed | Primary action | Secondary actions | Events / feedback |
|---|---|---|---|---|---|---|---|---|

## Module laws

1. Home does not calculate domain truth.
2. Pipeline does not become Person authority.
3. Activity does not recreate points/business rules.
4. Cartera does not infer Product Truth from policy UI labels.
5. Quotes does not invent product semantics in frontend.
6. Income does not equate estimate, generated, earned or paid.
7. Communication/Nash does not infer client intent or auto-send.
8. Person does not duplicate Timeline, Policy, Quote or Pipeline ledgers.
9. Documentation candidates do not become truth without governed review.
10. Coach does not produce human-worth, discipline, motivation, HR or compensation judgments.
11. Reports do not become metric owners.
12. Alfred orchestrates; it does not replace any authority.
