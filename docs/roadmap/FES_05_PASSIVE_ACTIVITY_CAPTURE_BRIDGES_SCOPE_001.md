```text
intent
≠ generation
≠ edit
≠ approval
≠ handoff
≠ external confirmation
≠ result
```

Opening WhatsApp, a phone link or a Calendar template proves only handoff.
Generated or edited language is not approved. Human approval is not external
execution. A confirmed external action is not automatically a confirmed
commercial result.

sequences. It does not yet extend the FES 01 canonical event allowlist.

Current FES 01 appointment events are marked `SUPPORTED_BY_FES01`. Locked
source-truth events outside that allowlist are marked
`REQUIRES_FES05B_EVENT_EXTENSION`. Calendar-template handoff remains bridge
evidence only. Pipeline stage event naming remains source-truth required.
