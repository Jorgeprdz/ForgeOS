- Activity plans require explicit human selection, dates, identity and confirmation.
- Confirmed plans enter an Activity review inbox; they do not automatically create tasks, calendar events or FES truth.
- Issued Forecast snapshots are SHA-256 protected and reconciled only after period close.
- Logout and advisor changes scrub tab-scoped Forecast context.
- Abort plus generation checks reject late cross-session results.
- Mobile, tablet and desktop layouts reserve safe space above the floating navigation pill.
