# Forge Design System

## Official redesign authority

The official visual redesign system is **Forge Aura Light 2026**, version 1.0.

Start here:

- `FORGE_AURA_LIGHT_2026_CANONICAL_DESIGN_SYSTEM.md` — normative visual implementation specification.
- `FORGE_AURA_LIGHT_2026_CANONICAL_AUTHORITY.md` — authority, precedence, supersession and change control.
- `FORGE_AURA_LIGHT_2026_UX_BEHAVIOR_DIRECTIVE_LOCKED.md` — locked normative UX behavior, decision architecture, forms, dashboard, alerts, progress, accessibility and responsive acceptance criteria.
- `../../00-governance/FORGE_AURA_LIGHT_2026_REDESIGN_COMPLIANCE_GATE.md` — mandatory pre-work and acceptance gate.
- `../../../adr/ADR-024 — Forge Aura Light 2026 Canonical Redesign Design Authority.txt` — ratified architectural decision.

The visual authority and the locked UX behavior directive must be applied together. Visual compliance without behavioral UX compliance is incomplete and must not be accepted.

Any new redesign that does not comply strictly with Aura Light 2026 is non-canonical and blocked.
