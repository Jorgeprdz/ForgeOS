ROOT_CAUSES_AND_REPAIRS=
1. Route modules were direct children of a 12-column viewport but lacked an explicit full-span contract. Added a scoped, visible direct-child contract with grid-column 1/-1, width 100% and min-width 0; [hidden] and display:contents semantics remain isolated.
2. Home first paint embedded advisor initials, online presence and business-looking static cards before authority resolution. Replaced with neutral session loading, hidden static placeholders and an explicit anonymous greeting/profile state.
3. Activity/Reports inherited the route-root column collapse. The shared root contract restores desktop width without changing FES authority or mutations.
4. Compensation inherited the collapse and incompatible light tokens. Added scoped dark Material tokens, wrapping/safe sizing, and full-width behavior.
5. Compensation recovery used long polling not owned by a verified session. Replaced with verified-session, event-driven recovery bound to AbortController and generation; cancellation occurs on route exit, logout/private scrub and non-authenticated state.
6. Pipeline bulk import trusted a DOM boundary that the local acceptance harness can set authenticated without a user. It now requires getSession().data.session.user.id before creating any file input or layer and otherwise fails closed explicitly.
