Scope

UI-M04 is the explicit Board scope selected after
NEXT=BOARD_SCOPE_SELECTION_AFTER_R16C. It authorizes extraction of the approved
Material 3 Inicio implementation into a reusable Forge application shell,
canonical navigation contract, Home module boundary and idempotent shell
lifecycle.

The approved source is docs/static-preview/forge-alive-material3/. Its rendered
identity, safe areas, responsive behavior, floating Nav Pill, global Alfred
command orb and Alfred sheet must remain visually equivalent.

Boundaries

UI-M04 does not authorize a visual redesign, a new visual language, a legacy
tree merge, a Cotizaciones migration, quote or product behavior changes,
backend or persistence work, Supabase changes, deployment, or direct mutation
of main.

Historical R16C and R16D records remain unchanged. The withdrawn local branch
feature/r16d-canonical-forge-shell carries no UI-M04 authority.
